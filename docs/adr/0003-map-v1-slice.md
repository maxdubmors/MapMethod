# First map slice: Poland grid filled by push-up logs

Map becomes the v1 start/root with a hand-tuned Poland boolean mask (~30x30) filled row by row north-to-south, west-to-east, one Cell per manual 10 push-up Log with next-Cell preview. Storage is Room `cells(orderIndex, row, col, filledAt)` in `:core:database` with callback prefill, `exportSchema = true`, and auto-migration for border refinements, following NiA's database/data split; `:feature:map:api` owns the NavKey and `:feature:map:impl` owns the offline Canvas (pinch 1x-4x, clamped pan, transient zoom) plus wiring. Chosen over DataStore/impl-local DB to support fast follow-ons (order strategies, manual pick, streaks, drawings) without rework, while keeping swipe full-screen fill an explicit non-goal that stays structurally unblocked.
